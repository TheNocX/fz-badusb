# Controlla le porte aperte

Payload per controllare le porte di connessione con il vostro flipper zero.

Controlla per prime le porte più comuni soggette ad attacchi hacker e poi continua scansionando un range dalla 1 alla 1500 (può essere modificabile).

Per modificare il range si devono cambiare le variabili $startrange e $endrange.

Per utilizzarlo bisogna solo sostituire "YOUR_DISCORD_WEBHOOK_TOKEN" con il vostro token (es. "https://discord.com/api/webhooks/...")

# Check open ports

Payload to control the connection ports with your Flipper Zero.

First, check the most common ports that are subject to hacker attacks, and then continue scanning a range from 1 to 1500 (which can be modified).

To change the range, you need to modify the variables $startrange and $endrange.

To use it, you just need to replace "YOUR_DISCORD_WEBHOOK_TOKEN" with your token (e.g. "https://discord.com/api/webhooks/...")
