
# Disabilita firewall e protezione in tempo reale

Payload per disabilitare il firewall e la protezione in tempo reale di windows con il vostro flipper zero.

Per lingue differenti dall'italiano sostituire "Sicurezza di Windows" con il nome nella lingua del computer (esempio in inglese: Windows Security)

# Disable firewall and real-time protection

Payload to disable firewall and real-time windows protection with your flipper zero.

For languages other than Italian, replace "Sicurezza di Windows" with the name in the language of your computer (example: Windows Security)
