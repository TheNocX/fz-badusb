# Recover Login Data and Browser History

Payload to retrieve the "history" and "Login Data" files of the Browsers (Chrome, Edge, Firefox and Opera) and send them to a discord server via webhook your flipper zero.

To use it, you just need to replace "YOUR_DISCORD_WEBHOOK_TOKEN" with your token (e.g. "https://discord.com/api/webhooks/...")
